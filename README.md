# cMod
A modular ontology suite for chronological processes, construction lifecycles, updates, and spatial scoping of built assets. cMod comprises four coordinated ontologies (OCP, OCCP, OULD, AMO) and builds on OWL-Time, PROV-O, and GeoSPARQL.  This repository is the public home of the suite identifiers. The RDF release follows with the dissertation.
